## 1. Dados Coletados

O aplicativo Vigília coleta os seguintes tipos de dados durante a sua
utilização:

### 1.1. Dados de identificação
- Nome completo
- E-mail
- Identificador único gerado pelo sistema de autenticação

### 1.2. Dados de monitoramento (por sessão)
- Score de fadiga calculado (0 a 100)
- Métricas de olhos, piscadas, bocejos e orientação da cabeça
- Estado detectado (Normal, Atenção, Fadigado)
- Nível de luz ambiente e luminosidade da imagem

### 1.3. Dados de contexto
- Localização (latitude, longitude, velocidade) — somente quando a
  permissão é concedida
- Dados de acelerômetro e giroscópio
- Timestamp de cada registro

## 2. Como os Dados São Usados

2.1. Os dados são utilizados exclusivamente para:
- Detectar sinais de fadiga e emitir alertas sonoros locais
- Manter histórico das suas sessões para consulta pessoal
- Sincronizar com a nuvem quando disponível

2.2. **Nenhum dado é vendido ou compartilhado com terceiros para fins
     comerciais.**

## 3. Armazenamento

3.1. Os dados são armazenados localmente no dispositivo (pasta privada do
     aplicativo) e sincronizados com o serviço Supabase quando há conexão
     com a internet.

3.2. Você pode exportar suas sessões a qualquer momento pela tela de
     Histórico.

## 4. Retenção

Os dados permanecem armazenados enquanto sua conta estiver ativa. Você pode
solicitar a exclusão dos seus dados através dos canais oficiais do
Aplicativo.

## 5. Segurança

5.1. A comunicação com o servidor é feita via HTTPS.

5.2. O acesso aos seus dados no servidor é protegido por políticas de
     Row-Level Security (RLS) que garantem que apenas você pode acessar seus
     próprios registros.

## 6. Câmera

6.1. A câmera é utilizada **exclusivamente** para análise de fadiga em
     tempo real no próprio dispositivo.

6.2. **Nenhum vídeo ou imagem é gravado, armazenado ou transmitido.** Os
     frames são processados em memória e descartados imediatamente após
     a análise.

## 7. Seus Direitos

Você tem direito a:
- Acessar os dados que armazenamos sobre você
- Corrigir dados incorretos
- Solicitar a exclusão da sua conta e todos os dados associados
- Retirar consentimento a qualquer momento (interrompendo o uso do
  Aplicativo)

## 8. Alterações nesta Política

Esta política pode ser atualizada. Alterações significativas serão
notificadas no próximo login e exigirão novo aceite.

## 9. Contato

Para exercer seus direitos ou tirar dúvidas sobre esta política, utilize os
canais oficiais informados no Aplicativo.
